# Projetos-Graduacao
Repositório que sintetiza os projetos/exercícios relacionados à graduação e às disciplinas cursadas.

[Tile Game](https://github.com/ViniReiwz/TrabalhoPraticoPOO-TileGame) ->> Projeto da disciplina de Programação Orientada à Objetos, consistindo na implementação de um jogo simples baseadoem células, utilizando a linguagem Java e as técnicas de POO;

[Chat em Grupo via socket TCP](https://github.com/ViniReiwz/Cliente-Servidor-bySocket_Redes-de-Computadores) ->> Projeto da disciplina de Redes de Computadores, que consiste num sistema básico de cliente servidor onde vários clientes podem se ligar ao servidor, receber e enviar mensagens uns aos outros.

[Otimização de problemas lineares](https://github.com/ViniReiwz/Progamacao-Matematica---Exercicios-SME0610-) ->> Exercícios de modelagem computacional para problemas de otimização.

[Escalonamento de Atividades Acadêmicas](https://github.com/ViniReiwz/Projeto-de-Otimizacao---Escalonamento-de-Atividades-Academicas) ->> Projeto de otimização a distribuição de salase provas para os alunos de graduação (modelagem e otimização de problemas lineares).

[Base de Dados](https://github.com/ViniReiwz/SCC0640_Base_de_Dados) ->> Exercícios da disciplina de Base de Dados, consistindo na implementação de banco de dados e consultas em PostgreSQL.

[Processamento Digital de Sinais](https://github.com/ViniReiwz/Processamento-Digital-de-Sinais-exerc-cios) ->> Exercícios e projetos relacionados ao processamento digital de sianis (imagens e sons, transformada de fourier, etc.).
